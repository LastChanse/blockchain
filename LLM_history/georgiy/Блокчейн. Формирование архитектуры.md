## Вопрос 2. План действий и команды для создания Django-проекта

**Пользователь:**

*2026-09-23 23:20*

Предложи пошаговый план: какие команды выполнить, чтобы получить такую структуру с нуля.

**ИИ-архитектор:**

*2026-09-23 23:20*

### Шаг 1. Создать виртуальное окружение и установить Django

```bash
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate         # Windows

pip install --upgrade pip
pip install django python-dotenv psycopg[binary]
pip freeze > requirements.txt
```

### Шаг 2. Создать Django-проект

```bash
django-admin startproject config .
```

Точка в конце — чтобы `manage.py` был в корне, а не в `config/`.

### Шаг 3. Создать приложения

```bash
python manage.py startapp clinic
python manage.py startapp portal
```

### Шаг 4. Создать структуру папок вручную

```bash
mkdir -p scripts
touch scripts/generate_nodes.py
touch .env.example .gitignore Dockerfile
touch docker-compose.yml docker-compose.portal.yml
```

### Шаг 5. Настроить `config/settings.py`

Добавить clinic и portal в INSTALLED_APPS:

```python
INSTALLED_APPS = [
    # ... стандартные ...
    "clinic",
    "portal",
]
```

### Шаг 6. Настроить `config/urls.py`

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("portal.urls")),
    path("clinic/", include("clinic.urls")),
]
```

### Шаг 7. Добавить url в `clinic/urls.py` и `portal/urls.py`

```python
# clinic/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path("", views.index, name="clinic_index"),
]
```

```python
# portal/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path("", views.index, name="portal_index"),
]
```

### Шаг 8. Заглушки во `views.py`

```python
from django.shortcuts import render

def index(request):
    return render(request, "clinic/index.html")
```

```python
from django.shortcuts import render

def index(request):
    return render(request, "portal/index.html")

def register(request):
    return render(request, "portal/register.html")

def apply(request):
    return render(request, "portal/apply.html")
```

### Шаг 10. Миграции и запуск

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```

**Итог:** после этих шагов структура полностью совпадает с той, что была описана.

## Вопрос 3. Скрипты для развёртывания

**Пользователь:**

*2026-09-24 01:03*

Какие минимальные скрипты развёртывания можно использовать для: `Dockerfile`, `docker-compose.yml` (портал + 2 клиники + 2 БД), `docker-compose.portal.yml` (только портал), `entrypoint.sh`.

**ИИ-архитектор:**

*2026-09-24 01:03*

### 1. `Dockerfile`

```dockerfile
FROM python:3.14-slim

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential libpq-dev \
 && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

RUN chmod +x scripts/entrypoint.sh
ENTRYPOINT ["scripts/entrypoint.sh"]
```

### 2. `scripts/entrypoint.sh`

```bash
#!/usr/bin/env bash
set -e

echo "NODE_ROLE=${NODE_ROLE:-portal}"
echo "NODE_ID=${NODE_ID:-portal}"

# Ждём БД (если роль clinic)
if [ "${NODE_ROLE}" = "clinic" ]; then
  echo "Waiting for database..."
  until python -c "import psycopg; psycopg.connect('${DATABASE_URL}')" 2>/dev/null; do
    sleep 1
  done
fi

python manage.py migrate --noinput
python manage.py collectstatic --noinput

exec python manage.py runserver 0.0.0.0:8000
```

Сделать исполняемым:

```bash
chmod +x scripts/entrypoint.sh
```

### 3. `docker-compose.yml` (портал + 2 клиники + 2 БД)

```yaml
services:
  portal:
    build: .
    env_file: .env
    environment:
      NODE_ROLE: portal
      NODE_ID: portal
    ports:
      - "8080:8000"
    restart: unless-stopped

  clinic0:
    build: .
    env_file: .env
    environment:
      NODE_ROLE: clinic
      NODE_ID: clinic0
      DATABASE_URL: postgres://clinic:clinic@db0:5432/clinic
    depends_on: [db0]

  db0:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: clinic
      POSTGRES_USER: clinic
      POSTGRES_PASSWORD: clinic
    volumes:
      - pgdata0:/var/lib/postgresql/data

  clinic1:
    build: .
    env_file: .env
    environment:
      NODE_ROLE: clinic
      NODE_ID: clinic1
      DATABASE_URL: postgres://clinic:clinic@db1:5432/clinic
    depends_on: [db1]

  db1:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: clinic
      POSTGRES_USER: clinic
      POSTGRES_PASSWORD: clinic
    volumes:
      - pgdata1:/var/lib/postgresql/data

volumes:
  pgdata0:
  pgdata1:
```

### 6. Команды для запуска

Полный стек (портал + 2 клиники + 2 БД):

```bash
docker compose up --build
```

Только портал:

```bash
docker compose -f docker-compose.portal.yml up --build
```

Остановить и удалить тома:

```bash
docker compose down -v
```
