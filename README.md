## Разработка

Работа ведётся параллельно в отдельных ветках:

| Ветка | Что делается |
|---|---|
| `main` | Стабильная версия |
| `dev` | Основная ветка разработки |
| `system-design` | Диаграммы, ТЗ, ADR |
| `frontend` | HTML, CSS, JS — клиентская часть |

Ветка `frontend` — параллельная разработка клиентской части.
Все изменения проходят код-ревью через Pull Request: `frontend` → `dev`.
